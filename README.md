# TopSchedule (浮窗课表)

TopSchedule 是一款 Android 课程表应用。支持通过教务系统网页登录或本地 HTML 课表文件导入课程，支持桌面微件、快捷方式与悬浮窗调用。

## 功能介绍

- **课程导入**：
  - 支持通过内置浏览器访问教务系统抓取课表，支持记忆账号密码与自动填充，支持切换电脑版/手机版 User-Agent。
  - 支持直接选择本地保存的 HTML 课表文件导入。
- **课表展示**：
  - 支持当日课表与周课表左右横向滑动切换。
  - 根据当前时间自动展示正在进行或下一节待上课程，并计算上课倒计时。
  - 支持解析与展示各周次分段任课教师，支持在课程详情中查看完整授课安排。
- **悬浮与快捷方式**：
  - 支持 Panels 等侧边栏应用通过快捷方式呼出悬浮面板，点击外部空白处或按返回键自动关闭。
  - 支持桌面微件与快捷设置磁贴。
- **系统适配**：
  - 支持深色模式。

## 构建说明

```bash
git clone https://github.com/misaka02/TopSchedule.git
cd TopSchedule
./gradlew assembleRelease
```
